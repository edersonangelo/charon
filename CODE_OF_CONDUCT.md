# Code of Conduct

Charon can be used, modified and maintained by anyone with an interest in doing
so. No affiliation, invitation or prior involvement is required, and none is
assumed.

## What gets reviewed

Contributions are judged on technical merit: whether the change is correct,
whether it survives the test suite and the lint gate, and whether it is
consistent with how the project is already built. That is the basis for
accepting or rejecting a change, and it is the extent of what review here
covers.

## What is expected

Keep discussion on the work — the code, the decision, the bug, the trade-off.
Technical disagreement is expected and useful.

Disrespect, harassment and deliberate disruption are not welcome. A thread that
goes there gets closed and the change stops being considered, without further
discussion.

## Abuse

GitHub provides abuse reporting and account-level blocking for every repository,
including this one: <https://github.com/contact/report-abuse>. That is the right
channel, and this project does not run a parallel process alongside it.
